# Order Tracking Hub
<!-- impeccable:product-schema 1 -->
## Platform
web
## Users
Order tracking users and an administrator identified by verified Telegram identity matching ADMIN_TELEGRAM_USER_ID.
## Product Purpose
Track shipments, notify via Telegram, Zalo, and the optional Windows Desktop System Tray app, and accept donations via PayOS.
## Capabilities and Constraints
Admin manages tracking, PayOS and bot settings in host-mounted .env and config.conf. Docker starts automatically. Fuel and outage features are removed.
