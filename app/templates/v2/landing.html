Tích hợp Partner REST API & Webhook ký số thời gian thực

Kết nối cửa hàng thương mại điện tử, OMS hoặc ERP của bạn qua chuẩn JSON RESTful v1. Tự động nhận bản tin HTTP POST kèm chữ ký bảo mật ngay khi đơn hàng chuyển trạng thái.

  • Xác thực linh hoạt qua Bearer Token hoặc X-API-Key, gắn mã tham chiếu nội bộ external_ref cho từng đơn.
  • Đẩy sự kiện tracking.created, tracking.updated và tracking.completed tức thì tới HTTPS endpoint của đối tác.
  • Chữ ký HMAC-SHA256 trên header X-OrderTracker-Signature chống giả mạo và phát lại bản tin.
Xem tài liệu tích hợp Quản lý API Key 
curl -X POST "{{ request.url_root.rstrip('/') }}/api/v1/trackings" \
  -H "Authorization: Bearer oth_live_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "tracking_number": "SPXVN048291049281",
    "carrier_id": "auto",
    "alias": "Đơn hàng #INV-2048",
    "external_ref": "INV-2048"
  }'
// X-OrderTracker-Event: tracking.updated
// X-OrderTracker-Signature: sha256=9f86d081884c7d659a2feaa0...
{

    },
