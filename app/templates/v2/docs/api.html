1. Tổng quan & Xác thực

Partner REST API cho phép hệ thống thương mại điện tử, ERP hoặc phần mềm quản lý đơn hàng đăng ký mã vận đơn, truy vấn lịch sử giao nhận chuẩn hóa và tự động nhận thông báo đẩy qua Webhook ngay khi hãng vận chuyển phát sinh mốc sự kiện mới.

Mọi yêu cầu tới {{ base_url }}/api/v1 sử dụng định dạng JSON (UTF-8) và xác thực bằng khóa oth_live_... khởi tạo tại trang API Đối tác & Webhook. Truyền khóa qua header Authorization: Bearer <API_KEY> hoặc X-API-Key.

The Partner REST API enables e-commerce storefronts, ERPs, and order management systems to register tracking numbers, query normalized carrier checkpoints, and receive real-time push webhooks whenever a shipment moves.

All requests to {{ base_url }}/api/v1 speak UTF-8 JSON and authenticate with an oth_live_... key generated in the Partner API & Webhook Console. Send your key via Authorization: Bearer <API_KEY> or the X-API-Key header.

curl -X GET "{{ base_url }}/api/v1/trackings?status=active" \
  -H "Authorization: Bearer oth_live_your_api_key" \
  -H "Accept: application/json"
const res = await fetch("{{ base_url }}/api/v1/trackings?status=active", {
  headers: {
    "Authorization": `Bearer ${process.env.ORDER_TRACKER_API_KEY}`,
    "Accept": "application/json"
  }
});
const payload = await res.json();
import os, requests

resp = requests.get(
    "{{ base_url }}/api/v1/trackings",
    params={"status": "active"},

4. Nhận cập nhật thời gian thực qua Webhook

Thay vì phải liên tục gọi API kiểm tra (polling), bạn có thể đăng ký một HTTPS URL tại trang API Đối tác & Webhook hoặc qua endpoint PUT /api/v1/webhook. Mỗi khi lịch trình đồng bộ phát hiện sự kiện mới từ nhà vận chuyển, hệ thống sẽ lập tức đẩy bản tin POST tới máy chủ của bạn.

Instead of polling, register an HTTPS endpoint in the Developer Console or via PUT /api/v1/webhook. Whenever our background scheduler or a manual sync detects new carrier checkpoints, Order Tracking Hub immediately delivers a signed POST request to your server.

5. Xác minh chữ ký bảo mật HMAC-SHA256

Mỗi yêu cầu Webhook gửi đi đều đính kèm các HTTP Header định danh và chữ ký số tạo từ Signing Secret (whsec_...) của riêng bạn:

  • X-OrderTracker-Event: Tên sự kiện (ví dụ tracking.updated).
  • X-OrderTracker-Delivery: Mã định danh duy nhất của lần gửi (dùng để chống xử lý trùng — idempotency).
  • X-OrderTracker-Timestamp: Unix timestamp (giây) lúc ký gói tin.
  • X-OrderTracker-Signature: Chuỗi sha256=<hex_digest> tính bằng HMAC_SHA256(secret, timestamp + "." + raw_body).

Every outbound webhook carries identifying headers and an HMAC signature computed with your Signing Secret (whsec_...):

  • X-OrderTracker-Event: Event name (e.g. tracking.updated).
  • X-OrderTracker-Delivery: Unique delivery ID for idempotent deduplication.
  • X-OrderTracker-Timestamp: Unix epoch timestamp (seconds) when signed.
  • X-OrderTracker-Signature: sha256=<hex_digest> computed as HMAC_SHA256(secret, timestamp + "." + raw_body).
import crypto from "node:crypto";

export function verifyOrderTrackerWebhook(rawBodyBuffer, headers, secret) {
  const timestamp = headers["x-ordertracker-timestamp"] || "";
  const signature = headers["x-ordertracker-signature"] || "";
  const signedPayload = Buffer.concat([Buffer.from(`${timestamp}.`), rawBodyBuffer]);
  const expected = "sha256=" + crypto.createHmac("sha256", secret).update(signedPayload).digest("hex");

  return (
    signature.length === expected.length &&
    crypto.timingSafeEqual(Buffer.from(signature), Buffer.from(expected))
  );
}
import hashlib, hmac

def verify_order_tracker_webhook(raw_body: bytes, timestamp: str, signature: str, secret: str) -> bool:
    signed_input = f"{timestamp}.".encode("utf-8") + raw_body
    expected = "sha256=" + hmac.new(secret.encode("utf-8"), signed_input, hashlib.sha256).hexdigest()
    return hmac.compare_digest(signature or "", expected)

6. Mã trạng thái HTTP & Xử lý lỗi

HTTP error.code Ý nghĩa
200 / 201 — Yêu cầu thành công ("success": true). Request succeeded ("success": true).
401 missing_api_key / invalid_api_key Thiếu API Key hoặc khóa đã bị thu hồi / không hợp lệ. API key was omitted, malformed, or revoked.
404 not_found Không tìm thấy vận đơn tương ứng thuộc tài khoản đối tác hiện tại. Tracking ID or number does not exist in your partner account.
422 validation_error / tracking_rejected Dữ liệu đầu vào thiếu trường bắt buộc, sai định dạng mã vận đơn hoặc URL Webhook không hợp lệ. Missing required field, unsupported tracking format, or disallowed webhook URL.
502 sync_failed API phía nhà vận chuyển tạm thời gián đoạn khi yêu cầu làm mới trực tiếp. Upstream carrier endpoint failed temporarily during live refresh.
